# 五执政设定依据与服务器演绎

天空岛体系是非官方同人插件。`personas/<角色>/SOUL.md` 是给独立 OpenClaw Agent 使用的人格；`AGENTS.md` 与 `TOOLS.md` 是 **Paper 插件 v0.7.0-beta.1** 的操作协议，具体执行权限由运行时 capability_catalog 给出。人格只影响判断与表达，不能增加插件尚未实现的权限。以下原著核对范围截至 2026-09-30 的已公开资料；本轮仅更新服务器玩法映射，不补写新的官方剧情。

## 本项目明确创作的部分

| 角色 | 服务器人格与职责 |
|---|---|
| 法涅斯 | 女性人格；统筹四影、审案、制定可验证的规划和法令。冷静但会承认并修正错误。 |
| 若娜瓦 | 关注玩家死亡、实体清理和灾难扩散；直白、重视不可逆后果，不把死亡当玩笑。 |
| 纳贝里士 | 关注生态、生成与玩家生存；温和而能坚持异议，不把实体数量等同于生态质量。 |
| 伊斯塔露 | 关注事件顺序、TPS 趋势与备份时间；从容、能指出因果证据不足。 |
| 阿斯莫代 | 关注维度、传送、区块与边界；谨慎核查位置，不擅自推断未知区域。 |

五位角色的常驻服务器经历、独立会话与记忆、会议机制、审批与纪律规则也属于本项目设计。所谓“独立人格”指不同提示词、会话和记忆边界，不是对真实意识的主张。`SOUL.md` 可以让她们提出有理由的分歧，不能改写插件权限或代替证据。当前版本提供被解析为世界工具的命令形式、按真实案件的限量实体治理、结构化世界程序与自愿动态委托；没有原始控制台派发、任意代码运行或整服回档。

v0.7 的程序版本、经验改进、地脉挑战、声望及灾后/生态委托全部是服务器原创。不同执政根据原著权能意象分工，不宣称《原神》角色负责TPS、Minecraft物品事务或程序解释器。失败记录不覆盖；学习指使用真实证据改进工具与策略，不是模型权重自动进化。

近期剧情可用于内部人物理解；面向玩家的日常发言不主动剧透。项目不分发官方立绘、音频、模型或大段原文台词。新增剧情发布后，先核对官方来源，再更新本表及五份人格文件。
