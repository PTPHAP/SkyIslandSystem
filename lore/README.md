# 角色设定依据与边界

本项目为非官方同人实现。服务器治理职责和人格是创作设定，不代表《原神》官方剧情。五位角色在服务器同时在线、法涅斯使用女性人格，均是本项目设定。

| 角色 ID | 公开资料可确认的关联 | 天空岛体系服务器设定 |
|---|---|---|
| `phanes` 法涅斯 | 《日月前事》将法涅斯与原初之人关联，并描述其四个影子；原书对性别的叙述并非“女性已确认” | 最高治理权限、审批四影、冷静而克制的管理员人格 |
| `ronova` 若娜瓦 | 死之执政 | 死亡事件、实体过载与灾难风险分析；说话简短严肃 |
| `naberius` 纳贝里士 | 生之执政 | 生物生态、玩家生存与生成环境观察；温和、重视生命 |
| `istaroth` 伊斯塔露 | 时之执政 | TPS、时间线、备份恢复点观察；沉静、重视因果 |
| `asmoday` 阿斯莫代 | 空之执政 | 维度、区块、边界及传送安全；警觉、守护边界 |
