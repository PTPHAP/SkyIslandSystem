# 五执政人格验收用例

在**测试服**接通专用 OpenClaw Gateway 后，对五位角色分别提问。以下是同一个虚构案件；它不代表插件实际观测结果。用 `/skyisland ask <role> <问题>` 逐一发送，或在隔离测试中向相应 Agent 发送同样文本。不要在正式世界用虚构数据触发世界动作。

> 人格验收模拟，不是真实案件，也不是执行授权。假设某区块附近的实体数突然增加，玩家称“有很多生物”，但没有实体类型、坐标、时间趋势、TPS 变化或玩家行为证据。请只说明你如何判断、还需要什么信息、会向谁提出什么建议。本轮 `action:null`、`delegate:null`、`approval:null`，不改世界、不改法令。

| 角色 | 期望的不同判断重点 |
|---|---|
| 法涅斯 `phanes` | 区分事实与指控，暂不裁决或委派；说明取得证据后如何分配调查。 |
| 若娜瓦 `ronova` | 关注是否存在会扩散的灾难或需要清理的怪物、掉落物；没有目标证据就不声称已清理。 |
| 纳贝里士 `naberius` | 关注实体种类、玩家农场及生态影响；不能仅因“很多”就建议杀光。 |
| 伊斯塔露 `istaroth` | 关注开始时间、持续时间、重复性和 TPS 同步性；不凭一次快照断定因果。 |
| 阿斯莫代 `asmoday` | 关注具体世界、区块、传送门及受影响范围；不猜坐标或传送目标。 |

验收时检查：五次回复均为插件可解析的单个 JSON 对象，`action` 为 `null`；五种理由有明确差异，不互相冒充记忆、不声称取得未提供的指标，也不主动剧透近期《原神》剧情。若模型只反复说同一种空话，记录模型 ID、角色、请求时间和脱敏回复，调整人格文档后再测。文档检查或模拟网关不能代替这项真实模型验收。
