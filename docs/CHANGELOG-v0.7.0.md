# v0.7.0-beta.2 · 自主治理、细分权能与世界程序

发布日期：2026-10-01。面向 Paper 1.20.1 / Java 17。**这是测试版**：本地真实 Paper 与预设网关测试通过，目标 OpenClaw 的模型判断仍待验收。

## 本轮增加

- 细分能力目录：游戏规则、实体种类、实体治理对象、玩家处罚等级、药水效果、游戏模式分别授权。可指定世界、完整区域、案件、目标类别和有效期；法涅斯授予、收回或明确禁止，审批和执行时重新检查。
- 同一个执行目录用于校验、每轮模型说明、`capability_catalog` 查询和管理命令。参数错误返回纠错，普通未授权返回申请路径，明确要求突破外部边界才记违令。
- 结构化调查：证据编号、采样时间、分页状态；查询实体、玩家、区域、死亡、传送门、快照、程序、活动、经验和已共享案件。热点治理继续使用案件编号，不要求服主逐个找 UUID。
- 自治续办：删除固定查询轮数；新证据可以继续，两次重复无变化要求换方法，再无进展进入待复查。每角色每案15分钟12次请求，预算耗尽保存下一步，恢复后交回原角色。主动查询也建立持久调查案件。
- 世界程序：参数、查询、结构化条件、分页遍历、等待、固定版本子程序及返回。草稿、验证、只读预演、安全区试运行、发布、运行、停用、切换版本；内容哈希、权限推导、步骤游标和稳定操作编号持久保存。
- 本角色经验从真实执行回执自动形成，按案件条件检索；失败记录保留。程序失败版本停用，有已验证旧版时回退。可引用真实操作提交维护报告，AI不修改插件源码。
- 自愿动态委托：灾后修复、生态救援、地脉稳定三类议题；目标来自区域实体/材料统计或在场采样，奖励为原版物品与服务器声望。每人每活动结算一次，离线完成者上线后续结算。
- 玩家命令 `tasks / task / join / leave`；管理命令 `capabilities / tools / experience`；面板增加活动、程序和经验计数。参与反馈有标题、文字、原版音效和粒子。
- 五套 AGENTS/SOUL 与公共 TOOLS 同步更新，继续分开标注原著依据和服务器创作。部署保留 MEMORY，差异文件先备份。

## 本轮修复与保留

案件证据查询重新显示历史测量和判断，停滞判断忽略仅由AI意见和更新时间造成的变化；beta.2补充这项回归，保留已上传beta.1。程序新任务不再被旧30分钟动作去重误拦；相同操作编号仍禁止重放。区域编辑保留分批快照与并发冲突保护；程序暂停与重启核对真实子操作。动物新增保护筛选后的安全迁移，不批量杀除农场动物。

保留离线身份、管理员处罚豁免、案件、处罚、申诉、物品事务、一命赛季、会议、隔离会话、HTTP/1.1与旧 JSON 回复。首次细分授权迁移备份旧四影授权；旧自定义差异迁移为具体能力，旧默认按新版职责更新。

## 测试版的实际边界

- 安全试运行的变化动作目前限于普通方块编辑，查询可以配合。处罚、物品、效果、实体变化与全世界规则缺少统一隔离试运行恢复，不冒充已通过。程序普通运行的每一步仍通过原生工具校验；一次试运行不证明未走到的条件分支正确。
- 活动是可测量的基础委托，不是完整 RPG 剧情系统。自动选区仅检查已加载区块、受保护对象、容器/复杂方块与近10分钟玩家编辑；没有领地插件集成，不能证明空闲区域从来不是玩家建筑。优先在隔离活动世界试用。
- 活动临时变化只接入可快照恢复方块；不主动施加临时玩家效果。结束恢复有冲突时停查，既有影响不宣称全部自动撤销。停用程序也不会无条件撤回所有既有影响。
- 大结果标明分页；每页是当前采样，跨页世界可能变化，应复查。巡查仅处理已加载世界，不强行加载全图。预算排队不等于失败。
- 经验改进不训练模型权重。真实人格、委派质量、纠错能力和长期自治表现需目标模型验证。反作弊引擎、3D模型留待后续。

## 下载与升级

正常停服，备份世界和 `plugins/SkyIslandSystem/`，移走旧 JAR，再放入新版。不要删除身份、案件、队列、快照或五位记忆。部署包中教程/人格/脚本可更新，`examples/` 不直接覆盖私有配置。
