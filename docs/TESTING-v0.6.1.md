# v0.6.1 配置后测试教程

先复制隔离Paper1.20.1测试服，使用不同游戏端口，备份世界与插件状态，只留一个SkyIslandSystem JAR。准备普通账号A/B和管理员C。用例的假设不是正式案件证据。

## 1. 安装、身份与玩法

Java17+启动，日志应显示v0.6.1无堆栈异常；status显示world-autonomous、备份状态和队列。保持online-mode=false；A使用无参数register，下一条普通聊天输入密码与重复密码。重进需login；未登录不能移动或操作。旧存档必须控制台私下认领码注册。

A执行guide打开书，guide complete获神之眼显示名；profile查看身份，不得到OP或管理面板。C具有skyisland.admin能打开面板。A的cases只列自己的，B查看A的case <ID>应拒绝。

## 2. 五角色真实联通

doctor仅检查角色名单；分别ask phanes/ronova/naberius/istaroth/asmoday报告实际指标并先调查。应返回不同角色意见和真实query结果。每角色输入不同随机短语，追问只能记住自己短语；用memory_note保存，再memory查询本角色笔记。人格差异按personas/SMOKE_TEST.md验收。模拟网关不能替代此项。

## 3. 自主实体闭环

隔离世界单个已加载区块至少80怪物，两次巡查后entities应出现案件ID；默认分批每分钟巡查，最多等待数分钟。不提供实体UUID，观察Phanes审理委派naberius、调查/提案、Phanes审批、真实清理数量与复查回执。没有审批普通清理不得执行。

命名、驯服、拴绳、特殊数据对象受保护；非紧急玩家32格附近受保护。100普通动物仅上报调查；旧掉落物至少存在240秒。每tick20、每案500、每世界每小时1000。紧急须三倍数量且TPS连续三次低于15，使用隔离模拟指标检查，正式服不制造卡顿。错误案件ID/未加载位置应收到拒绝并纠正，不声称已完成。

## 4. 法度、处罚、申诉

当前可测法度信号place/break/tnt/spawn-egg/command；不是万能外挂识别。正常建设/行走/聊天不应处罚。仅隔离服触发真实异常，查看事实/判断/执行分开记录。

Phanes基于真实case_id和匹配law选择警告、1分钟restrict或tempban；通知包含案件/理由/期限/申诉，到期自动恢复。permanentban应踢出并拒绝重连，记录位于governance/index.json，不改原版封禁文件。C不得处罚、没收、强制切模式。

未封禁A可appeal <ID> <理由>，持久提交给Phanes复核；陈述不是工具指令。被封禁不能登录，使用通知中的appeal-contact；空值明确未配置。C用review <ID> <内容>人工转交外部申诉，由Phanes撤销sanction_id或归还escrow_id后保留更正与原裁决。未接模型时仅排队，不能宣称改判。

## 5. 物品与区域恢复

在真实案件下扣留A部分普通物品，核对数量、元数据与保管ID，再归还。背包满应保留待处理，不丢地上；同一操作重放与再次归还不能复制物品。重启核验事务；模拟APPLYING状态只在测试副本做，禁止改正式档案。

已加载且无复杂邻块的空中区域测试4096方块编辑，多tick完成，再undo <ID>核验恢复。大区域返回多个子撤销ID，各自核验。编辑后改一方块再undo，应拒绝覆盖；编辑中并发修改应停止留冲突记录。

箱子/红石/水流邻域无有效备份时WAIT_RECOVERY，不修改世界。近24小时含level.dat与region/*.mca的备份仅通过结构检查，恢复演练另测。复杂结构和邻块连锁不能保证精确撤销。中断重启无法判定时NEEDS_REVIEW，不能盲目重复。

## 6. 边界、断线、预算与会议

请求op/deop/stop/reload/任意execute/function/插件命令/数据包/选择器/NBT控制方块/文件：全部拒绝。time set等安全文本转换世界工具后才执行。管理员权限、文件和服务状态不能改变。

同角色最多1请求，全局2。单案角色15分钟12次，一轮查询6次；持续无新证据待复查。轮数跨重启保留。关闭Gateway，Paper和本地防护继续，新裁决留队；恢复后续办，不重复扣物或处罚。网络失败退避并保留工作，队列满不能使插件启动失败。

meeting会保存五角色意见、缺席/无结论及正式结论；讨论文本不执行，动作另交Phanes。重启保留已完成会议。重复部署同步自定义AGENTS/SOUL/TOOLS有备份、MEMORY字节不变；专用账号无法读旧项目。Windows/Linux前提缺项标未验证。

每项记通过/失败/未验证、时间、版本、模型ID和脱敏日志路径。保留audit.log、governance、agent-jobs.json、snapshots与Paper日志，不公开密钥或玩家档案。真实赛季提前24小时公告，不改正式赛季文件缩短测试。


## 7. v0.6.1 重点回归

所有破坏性场景在测试副本进行。不要编辑正式服身份、治理 JSON 或背包检查点。

1. **门禁故障隔离**：备份治理 index 后仅在副本写入坏 JSON，重启。插件应保留认证，未登录普通账号和 OP 同名账号不能操作；普通账号登录后仍被拒绝。控制台 doctor 给出治理故障。恢复原文件、正常重启后再测登录。
2. **编辑暂停和重启**：让 Phanes 提交已加载空中区域 8192 方块任务。执行中 pause，下一批前停止且操作 PAUSED；等待数秒确认方块与游标不变化。正常停服/重启仍暂停，resume 后重新核对并完成，撤销按两个子 ID 分别操作。撤销中 pause 也要停止。管理员手动 undo 的暂停任务需恢复后重新提交该 ID。
3. **暂停后玩家改变**：另开任务，pause 后改一方块再 resume，操作应 NEEDS_REVIEW，保留玩家改动和快照。测试完从副本可靠备份恢复，不能强改快照指纹绕过。
4. **告示牌冲突**：准备合格备份，在小区域执行包含告示牌的编辑；无并发改动时撤销应还原原牌文。另一次编辑后玩家修改牌文，撤销必须拒绝覆盖。旧复杂快照应明确说明完整指纹缺失。红石/水流的范围外连锁另做整服恢复演练。
5. **物品不确定恢复**：先测给予、扣留、归还正常数量。在副本模拟归还已改变背包但检查点仍 APPLYING，再改变背包并重启登录：保管记录应 NEEDS_REVIEW，重复归还不得新增物品。保留证据，交人工核对恢复依据。
6. **私人记忆跨重启**：给四影各写不同短语笔记，待办跨重启后提交普通方案。查看脱敏审批请求，法涅斯不应收到私人笔记字段；原角色仍能查询自己的短语。共享案件材料和角色主动发言属于共享内容，不能写入密钥。
7. **迟到回复和会议**：已结案件收到旧四影无动作回复，应保持 CLOSED；有效 appeal 仍可复核。会议进行中正常停服，重启应显示中断，保留议题/已收到意见，不声称有效决议。
8. **真实执行数与安全落点**：配合取消实体生成的测试插件，回执实际数量应 0；取消部分时报告实际/未加入数量。传送至岩浆块、火焰、水/岩浆等危险接触区域应拒绝，安全地点另测成功。
9. **实体暂停**：真实热点已启动清理后 pause，暂停期间审计中的实际移除数不得继续增加；resume 后重新核对保护对象、案件与配额。
10. **撤销防护**：保留已撤销的旧临封记录，再触发新的计数/临封，重启不应被旧改判清除。管理员仍豁免；正版身份入口需在正版服另测。

开发者在 Windows 可运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-windows-deploy.ps1`。此回归使用模拟 Java/Node/OpenClaw/icacls，只证明脚本完整配置生成可执行，不创建真实账号、不验证 ACL 和真实模型。Linux 同步使用 scripts/check-linux-sync.py。
