# SkyIslandSystem v0.6.1 更新说明

本次针对 v0.6.0 代码审计发现的可靠性问题，不增加新的世界命令或玩法权限。

## 已修复

- **身份门禁**：先启用离线认证，再初始化治理。治理档案损坏时保留门禁、停止治理并显示诊断；普通玩家认证后仍暂拒进入，避免无法核验处罚。已认证管理员可查看故障，身份档案损坏仍拒绝登录。
- **角色隐私**：队列分别保存任务和案件上下文；兼容旧队列的安全续办，审批不再自动转发完整私人提示词。
- **暂停恢复**：编辑/撤销在下一批前保存游标并暂停；配置持久保存暂停状态。重启后保持暂停，恢复时重新核对区域和权能。实体清理在暂停期间不移除；重启后重新巡查。
- **恢复冲突**：新快照的完整方块实体状态指纹包含告示牌文字等附加数据；改变后拒绝覆盖。旧复杂快照缺少该指纹，停止自动撤销并保留材料。
- **物品归还**：先保存 RETURNING 和关联操作；重启核验不确定时锁定保管记录为 NEEDS_REVIEW，禁止重复归还。旧扣留操作不会把后续归还状态重新改成 HELD。
- **案件与会议**：已结案件忽略迟到回复，有效申诉仍可复核；会议开场与已收到的意见逐步保存，重启中断明确标记 INTERRUPTED，不冒充已形成决议。
- **执行回执**：模型文本显示为角色意见，完成状态以插件回执为准；实体生成报告实际加入世界的数量，被取消全部生成时实际为 0。
- **安全传送**：检查玩家接触区域、危险地面及未加载区块，拒绝岩浆块等伤害落点。
- **防护撤销**：自动改判只撤销匹配期限的旧临封，保留之后的防护计数与不同期限的新临封；正版登录的管理员豁免检查移至玩家权限可用阶段。
- **Windows**：修正自带 PowerShell 5.1 的压缩程序集、随机令牌、UTF-8 BOM 与 Java 标准错误输出兼容；完整配置生成模拟回归加入 GitHub CI。

## 升级

正常停服，备份世界和 `plugins/SkyIslandSystem/`，移走旧 JAR 后放入新 JAR。保留身份、治理、处罚、保管、队列、快照与私有记忆。部署脚本同步 AGENTS/SOUL/TOOLS 前备份差异文件，MEMORY 不覆盖。`ai-paused` 默认 false；原配置缺项自动按 false 读取，pause/resume 会保存它。

管理员手动撤销若暂停，恢复后再次提交原子快照 ID；AI 暂停编辑/撤销由 resume 自动续办。冲突及 NEEDS_REVIEW 不自动覆盖，先核查真实世界与恢复材料。旧复杂快照不能通过删除元数据绕过保护。

## 验证与限制

[验收记录](ACCEPTANCE-v0.6.1.md) · [测试与升级教程](TESTING-v0.6.1.md)。Java 单元、隔离 Paper 和模拟网关验证插件流程，真实 OpenClaw 模型、正式服长期误判/性能、真实账号与 ACL 安装仍待目标环境验证。备份结构测试不证明整服备份能够恢复。

本次没有加入 3D 模型、全种类外挂识别或新玩法，也不宣称模型智力升级。
