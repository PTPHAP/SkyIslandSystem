## 待验证与恢复边界

- 真实 OpenClaw 五角色人格、长期记忆、调查质量、自治判断与误判率；模拟网关不证明模型表现。
- 正版服的登录权限插件时序与管理员豁免；本轮使用离线服，不模拟 Mojang 验证。
- 正式机器 Windows/Linux 专用账号、ACL、模型认证、自启动和面板守护。Windows 配置生成测试不等于完整安装；Linux 构建/同步由 GitHub CI 检查。
- 高密度方块实体区域的完整指纹性能、长期低 TPS、复杂红石/水流的范围外变化与真实整服备份恢复。
- 真人客户端面板/书本/称号视觉与其他昵称插件兼容。
- 身份写入/治理存储的真实磁盘故障与恢复，初始化坏 JSON 已覆盖，但本轮没有制造真实磁盘满。

暂停在批次边界生效，不撤回已经完成的方块/移除。实体任务保留内存任务时可继续，重启后重新巡查，不承诺持久化扫描游标。管理员手动撤销暂停后须再次提交原子快照 ID。旧复杂快照保留材料但不自治覆盖。NEEDS_REVIEW 的物品、世界冲突和其他不确定操作需核查可靠恢复依据，不能重复执行。五类高频法度不等于万能外挂识别。

历史功能验收见 [v0.6.0 记录](ACCEPTANCE-v0.6.0.md)，其中历史临时路径同样不保证永远保留。升级与复测按 [v0.6.1 教程](TESTING-v0.6.1.md)。
