# SkyIslandSystem v0.6.0 更新说明

## 新增

- 持久请求队列、连续调查、真实回执、案件预算、操作去重和五角色私有笔记。
- 版本化JSON案件/操作/处罚/保管/玩家引导/会议；事实、陈述、判断、执行与更正分开。
- 分级处罚、离线账号永封、撤销、限时限制、个人案件/申诉与外部申诉转交。
- 物品给予/扣留/归还事务核对、管理员豁免、引导书和神之眼显示名身份。
- 分批区域编辑128方块/tick、4096/快照、最多256分片，并发冲突停止；实体自动热点与按案件清理。

## 修复与升级

移除未发布full-vanilla原始控制台授权，world-autonomous转换为受控世界工具。旧配置/命令授权备份迁移。保留HTTP/1.1、围栏JSON容错、提案回执/超时、法令冷却与断线防护。五套AGENTS/SOUL与公共TOOLS同步，差异文件先备份，MEMORY不覆盖。

工具准备失败现在保存明确的REJECTED回执，并回传角色限次纠错。本地高频防护处罚关联持久案件，支持天理复核撤销；踢出通知提供案件号、期限及申诉入口。案件与操作编号生成时检查已有记录，避免重启后碰撞。

升级前正常停服、备份世界和插件私有目录；替换JAR，保留身份/案件/处罚/保管/快照/队列/记忆。配置Gateway凭证和appeal-contact后按测试教程验收。

## 限制

真实OpenClaw与正式服长期自治未在本机验证，文档/工具升级不证明模型智力提升。确定性异常只有五类高频法度，不检测全部外挂；离线换号可规避身份。封禁后无法登录，外部申诉由服主配置并人工转交。复杂结构、邻块变化依赖外部备份；冲突须重新调查，不承诺任意变化精确可逆。大区域撤销按子快照；关联档案保守保留，长期规模需观察。3D模型、季节挑战、眼狩令、诅咒和剧情活动未加入。

详见[验收记录](ACCEPTANCE-v0.6.0.md)与[测试教程](TESTING-v0.6.0.md)。
