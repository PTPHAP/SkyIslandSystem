> **「愿星海中的每一座世界，都有人守望。」**

天空岛体系把服务器维护设计成一个有角色、有权能、有记忆边界的世界系统。五个独立 OpenClaw Agent 负责观察与判断，插件负责权限、动作白名单、审批链、证据和回滚边界。

## 🌌 五位执政

| 角色 | ID | 负责领域 | 定位 |
| :---: | :---: | :--- | :--- |
| **天理－法涅斯** | `phanes` | 全局治理 | 制定规划、调整法令、审批四影 |
| **死之执政－若娜瓦** | `ronova` | 死亡与灾难 | 死亡事件、实体过载、灾难风险 |
| **生之执政－纳贝里士** | `naberius` | 生命与生态 | 生物、玩家生存和生成压力 |
| **时之执政－伊斯塔露** | `istaroth` | 时间与稳定 | TPS、tick 时间线、备份状态 |
| **空之执政－阿斯莫代** | `asmoday` | 空间与边界 | 维度、区块、边界、传送安全 |

每位角色都有独立工作区、固定会话标识和独立记忆。普通案件由法涅斯先审理并委派四影；普通世界动作经过审批和插件校验。插件留证的严重高频事件允许对应执政直接收紧同信号法令。

### 自主办案

**发现 → 调查 → 法涅斯裁决或委派 → 四影方案与审批 → 执行回执 → 复查。**

- 分批巡查已加载区块，怪物、动物、旧掉落物连续超限自动建案。清理使用案件 ID，不需要玩家逐个提供 UUID。
- 角色可连续查询玩家状态、附近实体、区域材料、TPS 趋势、法度、备份、案件和执行记录。分页结果明确说明是否还有下一页。
- 插件将真实执行数量、拒绝原因与恢复编号交回角色；工具失败可以修正方案。格式错误作为纠错反馈，明确越权请求才进入纪律处分。
- 持久请求队列：每角色最多一个、全局两个模型请求。单角色单案每15分钟最多12次入队；有新证据继续调查，无变化两次要求换方法，再无进展待复查。预算恢复后按已保存进度续办，紧急治理先于会议和活动。
- 五角色私有办案笔记隔离；会话、工作区和 MEMORY.md 保留。天空岛会议保存意见与结论，讨论不会直接执行，正式动作交法涅斯提出。

### 世界工具与恢复

- 时间、天气、白名单游戏规则、世界边界、安全传送、白名单实体生成、实体治理、方块编辑、物品、效果与游戏模式。
- `world-autonomous` 接受游戏命令形式并转换为这些工具，**没有原始控制台派发权限**。旧 full-vanilla 配置和命令授权先备份再迁移。
- 普通世界治理无需管理员确认。复杂编辑仍须有近24小时结构可识别备份；没有恢复依据就保留案件，改选可恢复方案。
- 每 tick 最多编辑128方块、每快照4096；大区域拆成最多256份快照。编辑与撤销检测并发变化，冲突停止，不覆盖玩家后续修改。
- 怪物及四分钟以上旧掉落物按案件限量治理；普通动物先调查，可按保护状态安全迁移，不批量杀除。保护命名、驯服、拴绳、特殊数据对象。配额每tick20、每案500、每世界每小时1000。
- 极端实体数且TPS连续三次低于15的对应紧急案件可先止损；网关断线时确定性防护继续工作。

### 玩家治理与玩法

- 离线账号注册/登录、旧存档认领，一命赛季、死亡旁观和下一赛季恢复。
- 警告、限时行为限制、踢出、临时封禁、插件账号永久封禁与撤销。裁决必须引用真实案件、已实施法度与验证身份；管理员豁免处罚、没收与强制限制。
- 原始测量、玩家陈述、AI意见、执行和更正分开保存。正常活动仅保留十分钟聚合计数，不保存密码、无关聊天全文或持续位置轨迹。
- 物品给予、扣留、归还先保存事务，扣留保留原物品元数据；背包空间不足时保留待处理，不丢到地上。重启核对前后状态，无法确认时停止。
- 玩家引导书、可见神之眼身份、个人案件查询与申诉。称号使用显示名，不占用其他插件计分板，不授予OP。
- 被封禁账号不能登录；通知包含外部申诉链接。管理员用 review 转交外部陈述，法涅斯自主复核。未配置链接时明确提示。
- 死亡、跨维度、低TPS、规划和法令已有角色文字、标题及原版音效；本轮没有四影3D模型。

功能验证与限制见 [v0.7.0 验收记录](docs/ACCEPTANCE-v0.7.0.md)，实际测试步骤见 [测试教程](docs/TESTING-v0.7.0.md) 和 [20个真实模型案件](docs/MODEL-EVAL-v0.7.0.md)。真实模型的判断、人格和长期表现需要在目标 OpenClaw 上验收。

### 细分权能、自编工具与经验

- 权能分到具体规则、实体种类、效果、处罚等级等，可限定世界、区域、案件、目标类型及期限。五位共享调查能力；私人经验和记忆本人可读，案件按委派共享。
- 法涅斯自主授予和收回世界内能力。普通未授权请求返回申请路径，参数错误返回纠错；不能把正常纠错当违令处分。
- 世界程序采用结构化 JSON：参数、查询、条件、分页遍历、等待、固定版本子程序及返回。每步走原有执行器，内容哈希、操作编号和游标保存，禁止任意代码、文件、网络和控制台执行。
- 草稿→验证→只读预演→安全区试运行→发布→执行。当前变化试运行支持普通方块，其余动作尚无统一隔离恢复；未走到的分支也不算已验收。失败版停用、有已验证旧版时回退。
- 经验来自真实成功/失败回执，按问题条件检索。角色可引用真实操作提交维护报告；不会自行修改插件文件或训练模型权重。
- 准确字段与例子见 [世界工具手册](personas/TOOLS.md)。旧 JSON 动作和命令解析保持兼容。

### 自愿动态委托

灾后修复、生态救援与地脉稳定三类基础委托，由法涅斯定目标，四影提出本领域步骤。玩家查看目标/地点/期限/奖励，自愿报名退出；完成依实际实体/材料统计或在场采样判定。原版物品和服务器声望每人每活动一次，带标题、音效、粒子反馈。

自动选区仅使用已加载区块，排除容器、复杂方块、保护实体和最近玩家编辑；找不到则发布不编辑世界的合作调查。当前活动临时编辑只支持快照方块，不主动施加临时效果。**没有领地插件集成，不能证明一个空闲区从未属于玩家建筑**；先在隔离活动世界试用。结束恢复若有并发冲突，会保留玩家变化待核查。

## 🎮 怎么使用

### 安装

1. 下载[最新 Release JAR 或部署包 ZIP](https://github.com/PTPHAP/SkyIslandSystem/releases)。ZIP 同时包含 JAR、五份人格和部署教程。
2. 准备 Paper 1.20.1、Java 17+，并接受 Minecraft EULA。
3. 将 JAR 放入 `plugins/`，启动并正常停止一次。
4. 编辑 `plugins/SkyIslandSystem/config.yml`。
5. 将 Gateway token 写入私有的 `plugins/SkyIslandSystem/secrets.yml`。
6. 给管理员 `skyisland.admin`，执行 `/skyisland doctor` 和 `/skyisland status`。

完整部署见 [SETUP_GUIDE.md](SETUP_GUIDE.md)；交给 OpenClaw 使用 [DEPLOY_PROMPT.md](DEPLOY_PROMPT.md)。

### 离线模式注册

你的服务器保持 `online-mode=false` 时：

```text
/skyisland register
下一条普通聊天：密码 重复密码
```

旧存档玩家由控制台生成一次性认领码：

```text
skyisland claim <旧玩家名或UUID>
```

玩家随后使用 `/skyisland register`，下一条普通聊天输入 `密码 重复密码 认领码`。重进使用 `/skyisland login`，改密使用 `/skyisland passwd`。不要把密码直接写进斜杠命令，因为 Paper 可能先记录命令文本。

## 🔐 安全边界

- AI只获得世界工具，不能修改权限、配置、插件、密钥、网络或进程。op/deop、stop/reload、任意execute/function、插件命令、数据包、控制方块及NBT路径全部拒绝。
- 法涅斯可以调整四影的世界动作授权，不能改变外部边界。四影普通动作须审批；紧急例外由插件证据判定。
- 治理JSON、物品保管、快照和角色笔记由插件写入固定私有目录，AI没有通用文件工具。
- 保存独立系统账号与工作区仍需目标机操作系统权限隔离；部署脚本执行成功不证明隔离已通过。
- 结构快照不能保证流体、红石及邻块变化精确恢复，复杂编辑仍需外部备份。
- 离线身份只验证同名账号，不识别换号后的同一个现实玩家；不声称能检测所有飞行、透视或战斗外挂。
- 已结案件默认保留90天；关联处罚/保管记录与未完成案件保留。当前关联记录采取保守保留，不自动清除。

## 🧰 配置与构建

```yaml
gateway-url: "http://127.0.0.1:19789"
request-timeout-seconds: 210
review-interval-seconds: 600
meeting-interval-hours: 24
backup-directory: ""
max-simple-blocks-per-action: 4096
command-mode: "world-autonomous"
appeal-contact: "" # 被封禁玩家使用的外部申诉链接
```

Gateway 使用 HTTP/1.1，默认等待模型回复 210 秒。OpenClaw 必须使用独立状态目录、独立 token 和五份 Agent 工作区。插件断线时仍保留本地防护。

JDK 17 构建：

```powershell
gradlew.bat build
```

```bash
./gradlew build
```

当前版本输出：`build/libs/SkyIslandSystem-0.7.0-beta.2.jar`。运行 `gradlew.bat deployZip` / `./gradlew deployZip` 生成 `dist/` 部署 ZIP、JAR 和 SHA256 校验清单；测试驱动不包含在部署包中。
